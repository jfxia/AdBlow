### 本版更新（v1.0.4）

- **点击劫持拦截加固**。此前只检查通过 `addEventListener` 注册在 `window` / `document` 上的跳转处理器；
  现在同样拒绝 `document.onclick = …` 属性赋值、`<body onclick="…">` 行内属性，以及注册在
  `body` / `html` 上的跳转处理器。这类代码的典型表现是：页面加载后看不到广告，但鼠标随便点一下
  就跳到其他网站。
- **收窄弹窗放行条件**。跨站 `window.open` 现在只在用户点击的是链接、按钮一类控件时才放行；
  点击正文或空白处触发的跨站开窗会被拒绝。这是 popunder 广告 SDK 惯用的手法——在页面任意位置
  的第一次点击时弹出一个广告窗口。
- **新增「点击劫持观测」**。记录「点击普通内容后顶层页面跳到其他站点」的情况，可在规则管理页
  查看（站点、次数、最近时间、跳向域名），每行可单独删除。该功能只记录，不改变页面行为。
- 中文与英文 README 重写：每项功能补上前因后果，说明判定依据与取舍；正文改为一段一行。
