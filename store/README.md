# store/ —— 商店素材（手工维护，请勿自动覆盖）

## ⚠️ 给未来的自己 / 任何人

`store/store-1280x800-*.png` 是**手工挑选与截取的商店截图**，不是构建产物：

- 它们可能是**整屏截图**（含浏览器 UI 与真实页面，例如访问真实新闻站时点开扩展弹窗），
  因此尺寸可能不是"页面截图"那种精确数值；
- 它们**看起来"不规整"是正常的**，不代表文件损坏或被错误生成；
- **不要**用 `git checkout -- store/`、也不要重跑截图脚本去"修复"它们；
  有疑问请先问人。

2026-10-13 的真实事故：这几张图被自动化流程判为"尺寸不合规的残留"，
用 `git checkout` 还原了两次，抹掉了手工成果，且因为从未 `git add` 过而无法找回。
所以：**谁改的、什么时候改的，都必须立刻提交**。

## 若确实需要重做截图

```bash
node _probe/gen-store-shots.mjs          # 抓 raw-*（不碰交付物）
python tools/release/compose-store-shots.py   # 合成；**已存在交付物时会拒绝覆盖**
python tools/release/compose-store-shots.py --force   # 明确要求覆盖时才加 --force
```

更真实的做法（推荐，手工两步）：

1. 用加载了 AdBlow 的浏览器访问一个真实广告较多的站点（如 `edition.cnn.com`），
   停留片刻让扩展产生**真实统计**；
2. 点开扩展弹窗（此时显示的是该站点的真实数字）→ 截取 1280×800；
   打开「规则管理」→ 同样截取。

截图完成后**立刻提交**，不要留在工作区。

### 整屏截图要转成商店要求的尺寸

商店只接受 **1280×800 或 640×400**，整屏截图（1920×1080 等）会被直接拒。用：

```bash
# 等比缩放 + 补边（内容全保留，最安全）
python tools/release/fit-store-shot.py <你的截图.png> store/store-1280x800-popup-zhCN.png

# 等比缩放 + 居中裁剪（画面更满，边缘会被切掉一点）
python tools/release/fit-store-shot.py <你的截图.png> <输出.png> --crop
```

只做尺寸变换，不改动画面内容。若填错尺寸，最终清单会明确打印实际尺寸供核对。
